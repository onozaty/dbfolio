# dbfolio

Generate static HTML database documentation and ER diagrams from tbls schema.json.

> [!NOTE]
> dbfolio is under development. Currently only an overview page is generated.

## Usage

Generate `schema.json` with [tbls](https://github.com/k1LoW/tbls):

```bash
tbls out -t json -o schema.json
```

Then build the documentation:

```bash
dbfolio build schema.json
```

The output is written to `./dbfolio-docs` by default. Use `-o` to change it:

```bash
dbfolio build schema.json -o ./docs
```

### Output directory

- A missing or empty directory is used as is.
- A directory previously generated by dbfolio (it contains a `.dbfolio` marker file) is cleaned and regenerated.
- Any other non-empty directory is rejected. Use `--force` to write into it; existing files are kept (files with the same names are overwritten), and the directory is not marked as generated by dbfolio, so later builds never clean it.

## Supported tbls version

Tested with tbls v1.96.1.
